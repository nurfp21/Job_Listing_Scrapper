# Python Web Scraper Lowongan Kerja (Fake Jobs)

## 📌 Deskripsi Project
Project ini merupakan aplikasi **web scraping sederhana menggunakan Python** yang bertujuan untuk mengambil data lowongan kerja dari website *Fake Python Jobs*.

Website ini dibuat khusus untuk keperluan pembelajaran, sehingga aman digunakan oleh pemula untuk memahami dasar-dasar web scraping tanpa kendala hukum maupun proteksi anti-scraping.

Sumber website:  
https://realpython.github.io/fake-jobs/

## 🎯 Tujuan Project
Tujuan dari project ini adalah:
- Mempelajari cara mengambil data dari website menggunakan Python
- Memahami struktur HTML pada halaman web
- Mengambil (extract) data tertentu dari halaman web
- Menyimpan data hasil scraping ke dalam file CSV

## 📊 Data yang Diambil
Setiap lowongan kerja yang diambil berisi informasi berikut:
- Judul Pekerjaan (Job Title)
- Nama Perusahaan (Company Name)
- Lokasi (Location)
- URL Halaman Detail Pekerjaan

## 🛠 Teknologi yang Digunakan
- **Python**
- **Requests** – untuk mengambil halaman website
- **Beautiful Soup (bs4)** – untuk parsing dan membaca struktur HTML
- **CSV Module** – untuk menyimpan data hasil scraping ke dalam file CSV
